# Protocol → USDM 4.0: Evidence-Based Build Plan (v0.3)

**Status:** approved direction · supersedes the accuracy claims in `DESIGN.md` v0.2
**Date:** 2026-09-16
**Companion:** [`DESIGN.md`](DESIGN.md) (architecture) · [`docs/`](docs/index.md) (reference)

This plan replaces assumption with published evidence. Every load-bearing claim below
carries a citation. Where a widely-repeated number turned out to be folklore, it is
called out explicitly rather than quietly dropped.

---

## 0. Read this first: "full-proof conversion" is not achievable

The best published accuracy on this exact task — protocol PDF → structured fields, using
best-in-class RAG with a frontier model — is **89.0%**, i.e. roughly **1 field in 9 is
wrong** ([Babaeipour et al. 2026](https://arxiv.org/abs/2602.00052)). Worse, on long
documents frontier models suffer a **recall collapse**: 52.7% (GPT-5.5) and 48.6%
(Gemini 3.1 Pro) on ~358-page documents, *at high precision*
([LongExtractionBench](https://www.micro1.ai/benchmark/long-extraction)); and **0% valid
output** on a 369-field schema ([ExtractBench](https://arxiv.org/abs/2602.12247)).

**Silent omission — not wrong values — is the dominant failure mode.** That is the worst
possible failure in a regulated pipeline, because nothing looks broken.

So the product goal is restated:

> **Every field carries a verifiable verbatim citation to page and coordinates, a
> calibrated confidence, and a statistically-bounded auto-accept decision — with a
> 21 CFR Part 11 audit trail and measurably less reviewer time.**

That is defensible and differentiated. In a 13-coordinator study this class of tool cut
protocol-processing time **40%** (120.7 → 167.7 min) with quality rated 3.8/5 vs 2.7/5.

## 1. Corrections to our previous strategy

| # | What we believed | What the evidence shows |
|---|---|---|
| 1 | "The market bar is ~89% field / ~76% SoA" | **Not a matched pair, and one is not about USDM at all.** The 89% is a *vendor-authored* (Banting Health AI) n=23 study on a **bespoke non-USDM 6-category schema**, with a gold standard partly generated by LLMs. The 76% is [Kramer/MITRE 2026](https://esmed.org/MRA/mra/article/view/7362) — peer-reviewed, genuinely USDM-targeted — but it is a **whole-SoA pass rate** (22/29 protocols), not a field metric. Quoting them together implies a benchmark **that does not exist** |
| 2 | "Two independent paths ⇒ ~97–99% precision on the agreed set" | **False as stated.** Measured cross-model error correlation is **ρ = 0.74–0.82** (GPT-4o↔Claude 0.822) — 3–5× higher than human forecasters ([Oracle's Fingerprint](https://arxiv.org/pdf/2605.00844)); **48% of model mistakes replicate across families**. And errors from a shared OCR/layout stage are **ρ = 1.0** across every model. Agreement is a useful *feature*, never a guarantee |
| 3 | "Vision-first geometry: the LLM reads the grid" | **Inverted.** Specialist table models beat frontier VLMs on structure: MinerU2.5 (**1.2B**) scores **88.2 TEDS** vs Gemini-2.5-Pro 85.7 and Qwen2.5-VL-**72B** 82.2 ([MinerU2.5](https://arxiv.org/html/2509.22186v1)). But ACL 2025 finds *"MLLMs are far better"* at **cell text**. → **specialist owns the grid, VLM owns the content** |
| 4 | "Fork data4knowledge and conformance comes along" | `usdm4` is **GPL-3.0** (fine for internal use — that is not distribution — but a conscious decision). Executable USDM v4.0 CORE rules **only existed from Dec 2025**, and there are already **27 errata**, some flipping ERROR↔WARNING |
| 5 | "We must hand-label our 4 protocol PDFs to get ground truth" | **[`data4knowledge/usdm_data`](https://github.com/data4knowledge/usdm_data) already has ~20 real studies** mapped to USDM and CORE-validated, each traceable to a public NCT protocol PDF. Our 4 local PDFs become a held-out set instead |
| 6 | Confidence as a hand-tuned formula | **Fused multi-signal models reach 0.928 AUC** vs logprobs 0.705, verbalized confidence 0.692, self-consistency 0.744 ([ExtractConf](https://arxiv.org/pdf/2606.24420)) — and **document/grounding features dominate**, not model-internal uncertainty |

## 2. The three techniques that matter most

### 2.1 Verbatim quote + exact-substring verification — Tier 1, ~1 day, zero inference cost

Every field must arrive with a **quote**, which our code then locates in the source by
deterministic string search (plus a whitespace/ligature-normalised second pass; log which
pass succeeded as a confidence feature). A failed match is a **hard, non-probabilistic
reject**.

- Verbatim-grounded extraction: **93.0% vs 19.0%** exact match ([CogCanvas](https://arxiv.org/html/2601.00821v2))
- **98.87%** of extracted rows verbatim-verifiable in a production pipeline ([registry-bound extraction](https://arxiv.org/pdf/2606.00994))

It is also the **GAMP 5 argument**: deterministic code can be validated classically; LLM
output cannot. Push as much logic as possible into deterministic checks.

**Corollary: the model never emits coordinates.** It emits a quote; we resolve
page + character offset + bbox from the PDF's own character geometry. Model-emitted
coordinates are hallucination-prone and no benchmark supports them.

### 2.2 Completeness accounting — the silent-omission defence

Because recall collapse is the real enemy, each domain declares what it **expects** and we
reconcile: visit count from the design section vs columns in the stitched SoA; arm count
vs cells; activity rows vs footnote references. A mismatch is a **first-class finding**,
never a silent pass.

### 2.3 Conformal prediction with small-sample correction

Gives a *provable* bound: under exchangeability, the expected proportion of incorrect
fields among auto-accepted ones is **≤ α**
([Mohri & Hashimoto, ICML 2024](https://proceedings.mlr.press/v235/mohri24a.html)),
usable from **n ≈ 47** calibration points via
[SSBC](https://arxiv.org/html/2509.15349v1).

**State it precisely and no further.** The guarantee is **marginal, not per-field-type**,
and breaks when protocols stop being exchangeable (new sponsor template, new therapeutic
area, changed parsing stage). The cautionary tale: in
[medical entity extraction](https://arxiv.org/html/2603.00924) a global FDR of 2.3% masked
one category that required **100% rejection**.

## 3. Target architecture

```
L0  Born-digital substrate — PyMuPDF: text layer, char bboxes, bookmarks/ToC
     └─ character-level provenance for free. Never OCR a born-digital page.

L1  Layout + tables — Docling (MIT) ∥ MinerU2.5 (tables)
     └─ run both on table regions; disagreement is our cheapest quality signal

L2  ★ Multi-page SoA stitcher — CUSTOM. The risk centre.
     └─ Docling does not merge cross-page tables (issue #2976, open)
        MinerU merges but drops content on continuation pages (#4311, open)
        Clinical SoAs routinely span 3–6 pages → we must build and hard-gate this

L3  Section graph · study fingerprint · route plan  (ported, see §5)
     └─ typed sections, authority surfaces, PROHIBITED scopes, 4-axis scoping

L4  Sharded extraction — <40 fields/call, ≤5 nesting levels, narrow evidence windows
     └─ two-pass: free-text reasoning FIRST, then constrained JSON emission
     └─ tiered models (§4)

L5  ★ Grounding — model emits a VERBATIM QUOTE; our code resolves page+char+bbox
     └─ exact substring match → hard reject on failure

L6  Assurance — multi-signal confidence → conformal threshold → auto_accept/review/block
     └─ + completeness checks (expected vs found)

L7  Assembly — official usdm4 Assembler + input sanitizer + per-section builder fallback

L8  Validation — pydantic → d4k rules → CDISC CORE, + rule→repair map, bounded repair

L9  Review UI + Part 11 audit trail
```

**Governing principle, forced by the evidence:** *no single model ever owns both the grid
and the content of a table, and no single call ever owns more than ~40 schema fields.*

## 4. Models: Frontier LLMs + MinerU2.5 — accuracy-first strategy

All LLM traffic runs through **OpenRouter** behind `llm/router.py`, with roles declared in
`config/models.yaml` so any model is swappable per role without code changes. Role-based
routing is already implemented in `llm/openrouter.py` and `llm/config.py`.

**Strategy: frontier models by default; SLMs only when empirically proven to beat frontier
on that task.** This is accuracy-over-cost. The published evidence shows frontier models
outperform small models in nearly every domain (see analysis table below). One specialist
survives this test: **MinerU2.5** beats Gemini-2.5-Pro on table structure extraction.

> ⚠️ **Constraint, verified live (2026-09-17, 444 models on the catalog):** OpenRouter
> accepts a `logprobs` parameter but **not every provider supports it**.
> `meta-llama/llama-3.1-8b-instruct` lists `logprobs`/`top_logprobs` among its supported
> parameters; `anthropic/claude-sonnet-4.5` does not expose either. A design that leans on
> logprobs breaks *silently* on a model swap between those two. Logprobs are at most one
> optional feature, never load-bearing.

### 4.1 Role → Model mapping (verified live, 2026-09-17)

| Role | Model | Family | Why |
|---|---|---|---|
| **extract** (domain text, primary) | `anthropic/claude-sonnet-4.5` | Anthropic | C1–C4 extraction default tier |
| **extract_alt** (cross-family verifier) | `openai/gpt-5.1` | OpenAI | ρ=0.54 cross-family signal needed; no evidence a small model provides it at frontier accuracy |
| **verify** (quote↔value NLI, uncertain subset) | `google/gemini-3.1-pro-preview` | Google | Third family; frontier accuracy required for grounding |
| **vision** (SoA cell content, first pass) | `google/gemini-3.1-pro-preview` | Google | Frontier VLM; no evidence Qwen-3-VL-30B or any 30B matches frontier |
| **vision_alt** (cell cross-check) | `anthropic/claude-sonnet-4.5` | Anthropic | Different family from `vision` for cross-family signal |
| **hard_reasoning** (estimands, amendments) | `anthropic/claude-opus-4.8` | Anthropic | Escalation tier for hardest reasoning |
| **route** (section residue) | `anthropic/claude-sonnet-4.5` | Anthropic | After deterministic detection (bookmarks, headings, ToC) |

### 4.2 Why SLMs are not in the design

An earlier draft used small models (`Llama-3.1-8B`, `gpt-oss-20b`, `Qwen-3-8B`) as
cost-saving measures. **Frontier models outperform them in every measured domain** and
the cost savings are modest (10–30% per token) when the disk cache (Phase 0, task 0.3)
makes re-runs free. Test applied to each SLM candidate:

| Role candidate | SLM choice | Evidence vs frontier | Decision |
|---|---|---|---|
| Text extraction | Llama-3.1-8B | No task-matched frontier benchmark. Llama's strength is on quantized-weight tasks (legal/code), not clinical prose | **Frontier only** |
| Cross-family ensemble member | Llama-3.1-8B / Qwen-3-8B | Cross-family ρ=0.54 signal needs diversity, not model size. Using a *stronger* second family achieves both | **Frontier, different family** |
| NLI (quote↔value) | MiniCheck-FT5 (770M) | **74.7% balanced acc ≈ GPT-4 75.3%**. But GPT-4 was the 2023 frontier; GPT-5.1 is higher. Frontier NLI accuracy is unmeasured | **Frontier** |
| Section routing | gpt-oss-20b | "Structured generation helps classification" — but no direct comparison to frontier on routing. Cost cut: ~30% per token | **Deterministic first** (bookmarks, ToC, headings); frontier for residue |
| Entity spotting (drugs/labs/visits) | GLiNER-BioMed | 59.8% / 70.4% F1 is good for a 0.3B model. Frontier zero-shot biomedical NER unknown but likely higher | **Support signal only** (for completeness accounting) |
| High-volume narrow fields | QLoRA 8B | *Scientific Reports*: **90.0% exact match, non-inferior to second-human**. But never compared to frontier LLM on same fields | **Not now.** Revisit after Phase 4 only if a domain's frontier accuracy < the tuning paper's 90% |

**Do not build:** SmolDocling near tables (**0.52 TEDS** vs TableFormer 0.89); verbalized
confidence as a gate (**0.692 AUC**); the extracting model as its own judge
(**self-preference bias up to +90%**).

**Two subtle rules:**
- **Two-pass emission everywhere** — free-text reasoning, *then* constrained JSON. This
  resolves [Tam et al.](https://arxiv.org/abs/2408.02442) vs the
  [.txt rebuttal](https://blog.dottxt.ai/say-what-you-mean.html) at near-zero cost.
- **If sampling for self-consistency, sample in YAML/free-text, vote, then emit JSON
  once.** JSON-constrained decoding *collapses* answer diversity (modal share 41%→64%),
  so voting under a JSON grammar is far less independent than it looks.
- **Cross-family verification only** (ρ=0.54 cross vs 0.77 within), and **verify only the
  uncertain subset** to control cost.

## 7. Risks

- **Silent omission** (~50% recall on long docs) → completeness accounting + sharded
  schemas + narrow routing. *The* risk.
- **Multi-page SoA stitching is unsolved** by every available tool → custom build, fail
  loudly, gated by a hand-labelled set of 30–50 real multi-page SoAs.
- **Correlated model errors (ρ 0.74–0.82)** → never claim consensus ⇒ accuracy; measure
  our own pairwise correlation before paying for a third model.
- **Shared parsing errors are ρ = 1.0** → no ensemble fixes them; hence document-quality
  features rank first in the confidence model.
- **Conformal overclaiming** → marginal ≠ conditional; monitor drift; global bound first,
  per-class only at ~20+ protocols.
- **`usdm4` GPL-3.0** → internal use is not distribution, but record the decision;
  `soa2usdm` (MIT) is the clean alternative for SoA logic.
- **Standards churn** → pin **three** things independently: USDM model version, CORE rule-set
  version, errata revision. Treat rule severity as data, not a constant.
- **Regulatory posture** → design toward FDA's *operational-efficiency* exclusion by
  requiring human certification of every field. **Do not self-certify the Context of
  Use** — route it through regulatory affairs.
  [ICH E6(R3)](https://www.ct-toolkit.ac.uk/news/summary-key-changes-ich-e6-r3-guidelines)
  now makes **traceability an explicit obligation**, which is exactly what L5 delivers.

## 8. Verification

1. **Phase 0** — assembler pass-rate number printed; `usdm_data` corpus loaded, N studies confirmed.
2. **Phase 1** — on a real protocol, **100% of emitted fields pass exact-substring quote
   verification** (hard gate) and the structural gate is clean.
3. **Phase 2** — stitcher reproduces a hand-labelled 5-page SoA; mechanical re-derivation
   agrees with LLM extraction on ≥95% of cells, disagreements surfaced not merged.
4. **Phase 3** — measured accuracy delta with routing on vs off; ≥1 prohibited-surface leak
   documented as prevented.
5. **Phase 4** — risk-coverage curve published; realized error among auto-accepted ≤ α on
   held-out protocols.
6. **Ongoing CI** — fail on empty packages, files >400 lines, hard-coded paths, or any field
   lacking evidence.
